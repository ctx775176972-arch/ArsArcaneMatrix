# 奥术矩阵空岛：初版测试

仅用于新建测试存档，尚未完成游戏内验证。不要替换已有世界的生成器。

## 开启

在 `config/ars_arcane_matrix-common.toml` 设置 `enableSkyblock = true`，无需重启游戏。在主菜单配置后创建世界即可；通过 Cloth Config 在未开放局域网的单人世界内保存此开关时自动重新加载数据包。手动编辑文件后使用 `/reload` 或重新进入世界。
新建世界时选择「奥术矩阵空岛」。配置仅启用配方与开局物资；地形处理仅针对此专用世界类型，不转换普通存档。

主世界保留群系与末地传送门框架，起点为 (0,81,0) 的 5×5 泥土平台；泥土下方有一层同尺寸的永久法师方块。
下界保留群系及要塞主要方块；末地采用原版生成。
下界传送门由原版玩家传送机制创建，不在运行中清理区块。

## 开局

岛中心预先种植一棵繁茂至高木树苗，不向玩家背包赠送树苗。
每个玩家领取一次：骨粉 ×64、触摸—法师方块—强化施法者卷册、触摸—粉碎施法者卷册。
不赠送冰块、水桶或草方块。

## 空岛专用配方

| 输入 | 产物 |
| --- | --- |
| 粉碎法师方块 | 圆石 ×1 必出；铁粒 50% 出 1～3 个、金粒 30% 出 1～3 个、青金石 5% 出 1 个，分别独立判定 |
| 粉碎繁茂至高木树苗 | 小麦种子 ×2 必出 |
| 粉碎苔藓块 | 青金石 ×1 概率 50%；粗铜 ×1 概率 25%，独立判定；苔藓块被消耗 |
| 粉碎魔源石 | 红石 ×1 必出；钻石 ×1 概率 1% |
| 灌注空桶，基座炼药锅 | 水桶 ×1，20 魔源，炼药锅不消耗 |
| 灌注空桶，基座圆石 | 熔岩桶 ×1，500 魔源，圆石不消耗 |

## 测试重点

菌丝不再使用空岛粉碎配方。通用反应釜配方：菌丝 ×8 → 棕色蘑菇 ×2，消耗200魔源、耗时5秒，不需要流体。

1. 普通世界与关闭空岛配置时不出现空岛资源配方、不赠送物资。
2. 专用世界起点安全、只有泥土；领取物资 ID 正确。重进及死亡不重复领取。
3. 强化法师方块永久存在；两种方块可被赠送卷册命中和粉碎，目标被移除，不复制掉落。
4. 圆石不会被粉碎配方直接放回世界；圆石—砂砾—沙子—玻璃链正常。
5. 制作魔源石后通过粉碎稳定获得红石，钻石为低概率；概率不是次数保底。检查 JEI 粉碎页面显示此配方。
6. 首罐魔源启动后，两种空桶灌注可用，催化剂不消耗。
7. 进入下界可安全落脚，要塞可寻找，箱子与烈焰人刷怪笼可用。
8. 末影之眼寻找要塞，12 个框架完整且朝向正确；激活并进入正常末地。

沼泽、海滨、丛林的新群系仪式板尚未加入本次初版。

启动时先用骨粉种树取得木材和更多树苗，再粉碎多余的繁茂树苗获取种子。
保留树苗自然生长，通过农艺魔源通道积攒第一份魔源；骨粉催生不产生这份魔源。
攒出魔源后可灌注水桶建立农田，不要粉碎唯一的开局树苗。
