# Ars Nouveau texture permission

This record preserves permission requested by xuemo3rd and granted by Baileybuncle on Discord for **ArsArcaneMatrix** and **Ars Misc**.

The request specifically asks to use recolored or modified Ars Nouveau textures in public releases, with credit to the original assets. Baileybuncle replied:

> Yes you can use them for ars addons

The original screenshots are kept privately and are not included in this repository.

## Attribution and scope

Ars Nouveau textures used or modified under this permission remain the property of their respective authors. They are not relicensed under this repository's MIT license. Credit: **Ars Nouveau and its asset authors**.

This record documents the texture permission shown in the conversation. It does not claim separate permission for models or other assets not expressly covered by the request.
