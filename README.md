# Ars Arcane Matrix

Ars Arcane Matrix is a NeoForge addon for Ars Nouveau focused on late-game Source generation, multiblock machinery, and automation.

The mod adds the Arcane Matrix Core, Arcane Mine, Arcane Amplifier, and Arcane Imbuement Core. Multiblock controllers provide an in-world structure preview when used with an empty hand, and all mod content is documented in a dedicated Ars Arcane Matrix section inside the Ars Nouveau spell book.

English and Simplified Chinese localizations are included. Optional JEI and Jade integrations provide additional recipe and status information when those mods are installed.

Ars Arcane Matrix requires Minecraft with NeoForge and Ars Nouveau.
